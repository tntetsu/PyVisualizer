# ADR-005: Python の対象拡大（基本）― 内包表記・set・del・スライスへの代入・ループの else・% 書式・*args/**kwargs

- ステータス: 採用
- 日付: 2026-11-25

## 背景

Phase 5 で、MVP（計画書 4.1 節）の対象外だった構文のうち、入門の教材によく出るものを入れる。

- 内包表記
- set
- `del`
- スライスへの代入
- `for`/`while` の `else`
- 文字列の `%` 書式
- `*args`/`**kwargs`・キーワード専用引数

意味論は CPython に合わせる（出力・例外の種類・変数の状態の変化を CPython と比べるテスト）。ただし、次の 3 点は CPython と同じにできない、または PyVisualizer の見せ方として決める必要があった。

## 利用者に見える例

テストは `tests/adr-examples.test.js`（ADR-005 例1〜3）。3 件とも、入れる前（`2574c30`）では失敗する（構文エラーになる）ことを確かめた。

1. `squares = [x * x for x in range(3)]` を「人」の単位で進めると、内包表記の各回（`x` が 0・1・2）で止まる。終わったあとは、変数に `x` は残らない（`squares` は `[0, 1, 4]`）
2. `s = {3, 1, 2}`・`s.add(0)` のあと `print(s)` は `{3, 1, 2, 0}` と、入れた順に表示される。CPython では `{0, 1, 2, 3}` のように、ハッシュ値で決まる順になる
3. `g = (x * 2 for x in range(3))` のあと `print(g)` は `[0, 2, 4]` と表示される。CPython では `<generator object <genexpr> at 0x…>` と表示される。`sum(x for x in [1, 2, 3])` のような普通の使い方では、結果は CPython と同じ（`6`）

## 決定

- **内包表記**：Python 3 と同じく、内包表記ごとのスコープを作る（ループ変数が外に漏れない）。最初の `for` の `in` の後ろだけを外側のスコープで評価する。各回のループ変数への代入は、`for` 文と同じく `LoopBinding` として記録する（[ADR-003](ADR-003-python-trace-additions.md)）
- **set**：tuple と同じく、印（`__pyset__`）を付けた JS の配列で表す。要素の検索には辞書と同じ索引（`hashKey`）を使う。表示は入れた順。CPython の集合の順序はハッシュ値とテーブルの大きさで決まり、再現できないため。配列のビューで要素を見られる（ValueModel の約束「sequence は JS の配列」を守れる）
- **ジェネレーター式**：ジェネレーター（`yield`）は対象外なので、その場で全部計算した list として扱う
- **`del`**：変数（関数の中ではローカル変数になる）、list の要素とスライス、辞書のキー
- **スライスへの代入**：step が 1 なら長さが変わってよい。拡張スライスは同じ長さのときだけ
- **ループの `else`**：`break` しなかったときだけ実行する（AST の `ForOfStatement`・`WhileStatement` に `orelse` を足した）
- **`%` 書式**：`%[フラグ][幅][.精度]型`（`d i s r f e g x X o c %`）。`%(名前)s` は未対応
- **引数**：`*args` は tuple、`**kwargs` は dict、`*` の後ろはキーワード専用。関数の変数は CPython と同じ順（位置引数 → キーワード専用引数 → `*args` → `**kwargs`）で作る。呼び出しでは `f(*xs, **d)` を使える

## 結果

- CPython との比較テスト（`tests/cases/semantics_phase5_basic.py` と、例外の 4 件）が一致する
- 変数の状態の比較テストは、2 つの場所で両者の動きが違うので、チェックしないことにした
  - 内包表記の中：CPython 3.12 は内包表記を呼び出し元のフレームの中で実行するため（PEP 709）、途中の変数が一時的に見える
  - ジェネレーター式のフレーム
- 集合は、テストでは要素を並べ替えて比べる
- 空の集合は、ビューでは `{}` と表示される（`repr` は `set()`。コンソールの出力は `set()`）
- 制御フローのビューは、ループの `else` のブロックを表示しない
