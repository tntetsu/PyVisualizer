# ADR-009: 値の表記の細部を Python の書き方にし、制御フローにループの else を出す

- ステータス: 採用
- 日付: 2026-11-25

## 背景

ADR-004 で値を Python の書き方で見せるようにしたが、かっこの組み立ては JSVisualizer のビューのもの（JS の書き方）のままだった。そのため、次の表示が Python の `repr` と違っていた（[phase4-report.md](../phase4-report.md) 5 節、[phase5-report.md](../phase5-report.md) 4 節）。

- 辞書のかっこの内側に空白が入る（`{ 'a': 1 }`。空の辞書は `{  }`）
- 空の集合が `{}`（空の辞書と同じ）
- 1 要素のタプルが `(5)`（ただの数と見分けにくい）
- インスタンスが辞書と同じ `{ name: 'Rex' }`。コールスタックの見出しでは `{…}` で、何の値かわからない

また、制御フローのビューが `for`・`while` の `else` を表示していなかった。

## 利用者に見える例

テストは `tests/adr-examples.test.js`（ADR-009 例1〜4）。4 件とも、直す前のコードで失敗することを確かめた。

| # | プログラム | 表示（以前 → 今） |
|---|---|---|
| 1 | `d = {"a": 1}`、`e = {}`、`s = set()` | 変数のビュー：`{ 'a': 1 }`・`{  }`・`{}` → `{'a': 1}`・`{}`・`set()` |
| 2 | `t = (5,)` | 変数のビュー・式評価・置換：`(5)` → `(5,)` |
| 3 | `class Dog:` で `self.name = name` とし、`d = Dog("Rex")` | 変数のビュー：`{ name: 'Rex' }` → `Dog{name: 'Rex'}`。属性のないインスタンスは `{  }` → `Cat{}`。コールスタックの見出し：`bark({…})` → `bark(Dog{…})` |
| 4 | 下のプログラム | 制御フローのビュー：`for` の下に `else` とその中の `print("not found")` が表示される（以前は表示されなかった）。`break` で抜けたので、その行は実行されていない（グレー） |

例4のプログラム：

```python
for x in [1, 2, 3]:
    if x == 2:
        break
else:
    print("not found")
print("done")
```

インスタンスの書き方は、辞書（`{'name': 'Rex'}`）とクラス名とキーの引用符で区別できる `Dog{name: 'Rex'}` にした（2026-11-25 決定。`Dog(name='Rex')` は `__init__` の呼び出しと誤解されやすく、`<Dog name='Rex'>` は見慣れないため採らなかった）。

## 決定

- JSVisualizer の作業ブランチ `feature/multilang` で、ビューのかっこの組み立て（変数・実行トレース・式評価・置換・配列・呼び出しツリー・ライフタイム・コールスタックの見出しなど 16 か所）を `utils/value-model.js` の `wrapItems()`・`elided()` にまとめた。言語ごとの違いは、言語プロファイルの `valueModel` の省略できる項目で与える（JSVisualizer の ADR-055 に追記）
  - `padMapping`：辞書・オブジェクトのかっこの内側に空白を入れるか（JS は入れる、Python は入れない）
  - `emptyText(v)`：要素が 0 個のときの書き方（Python の集合は `set()`）
  - `trailingComma(v, count)`：最後にコンマを付けるか（Python の 1 要素のタプル）
- Python のインスタンスのかっこを `Dog{`・`}` にした（`src/lang/python.js`）
- 制御フローのビューは、ループの `orelse`（Python の `for`・`while` の `else`）を、ループ本体の下に `else` の見出しを付けて描く。JS の AST には `orelse` がないので、JS 版は変わらない

## 結果

- 値の表記が、Python の `repr` と同じになった（インスタンスを除く。インスタンスは中身が見えるように `Dog{…}` で書く）
- JS 版の画面が変わらないことを、JSVisualizer の変更前後のビルドで、全サンプル・記事の題材 × 全タブ × 5 位置の画面の HTML を比べて確かめた
- ADR-004 の例3・ADR-006 の例5（テストを含む）を、新しい書き方に合わせた
