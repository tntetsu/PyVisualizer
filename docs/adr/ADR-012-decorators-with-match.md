# ADR-012: デコレーター・with・match を入れる

- ステータス: 採用
- 日付: 2026-11-25

## 背景

Phase 5 では、デコレーター・`with`・`match` を対象外にしていた（[phase5-report.md](../phase5-report.md) 4 節）。公開後、授業で使う可能性があるとして入れることにした（2026-11-25）。ジェネレーター（`yield`）は、評価器を作り直す必要があるので見送った。`open()` によるファイルの読み書きも、画面の設計から考える必要があるので見送った（同日の決定）。

`match` は、使うと「予期しないインデントがあります」という誤ったメッセージが出ていた（インデントの検査が `match`・`case` をブロックの見出しとして扱っていなかった）。

## 利用者に見える例

テストは `tests/adr-examples.test.js`（ADR-012 例1〜6）。6 件とも、入れる前のコードで失敗することを確かめた。

1. 自作のデコレーター（`@loud`）と、`@property`（`@v.setter` を含む）・`@staticmethod`・`@classmethod` が使える
2. `with Box() as b:` は `__enter__` と `__exit__` を呼ぶ。本体で例外が起きると `__exit__` に例外の型・値・トレースバックが渡り、`__exit__` が `True` を返すと例外はそこで止まる
3. `match` で、リテラル・`|`・並び（`[a, *rest]`）・辞書（`{"name": n}`）・クラス（`str() as s`、`Point(x=0, y=y)`）・`_`・`if` の条件が使える
4. 「人」のステップは、当てはまった `case` の行と、`with … as` の代入で止まる
5. 制御フローのビューは、`match` の `case` を `if … else` の連なりとして描く。各 `case` の「×N」は、その `case` を試した回数
6. `with open("data.txt") as f:` は、「open() によるファイルの読み書きはまだ対応していません（データはプログラムの中に書いてください）」と表示される

## 決定

- **デコレーター**：デコレーターの式を上から評価し、関数（またはクラス）を定義したあと、下のデコレーターから順に適用して名前に代入する（CPython と同じ順）
- **`staticmethod`・`classmethod`・`property`**：包んだ値として持ち、属性を取り出すとき（`getAttr`）・代入するとき（`setAttr`）に CPython と同じ規則で扱う。`property` はインスタンスの属性より先に見る。ビューでは関数として見せる
- **`with`**：自作のコンテキストマネージャー（`__enter__`・`__exit__` を持つインスタンス）に対応する。複数の項目は入れ子の `with` と同じ。`__exit__` の 3 番目の引数には、`<traceback object>` と表示される代わりのオブジェクトを渡す（中身は持たない）。`as` の代入を `WithBinding` として記録する（「人」のステップが止まる）
- **`match`**：パターンは、リテラル（`None`・`True`・`False` は `is` で比べる）・取り込み・`_`・`|`・`as`・並び（`*` を含む。文字列・辞書・集合は当てはまらない）・辞書（`**rest` を含む）・クラス（組み込みの型は位置引数 1 つで値そのもの、自作のクラスは `__match_args__`、キーワードは属性）・値（`Color.RED`）。`case` を試すたびに `CaseTest`（値は当てはまったか）、当てはまったら `CaseBinding`（「人」のステップが止まる）として記録する
- **構文の変換**：`match`・`case` はソフトキーワードなので、インデントの検査では行末が「:」のときだけ見出しの行とみなす。Lezer は `case str():`・`case []:` の空の中身に幅 0 のエラーノードを作るので、それは誤りとみなさない
- **制御フローのビュー**（JSVisualizer の作業ブランチ `feature/multilang`）：`DecoratedStatement`（定義と同じ）・`WithStatement`（見出しの行のあとに本体）・`MatchStatement`（`case` の `if … else` の連なり）を描き、その中の関数もスコープとして描く。JS の AST にはこれらのノード型がないので、JS 版は変わらない
- **`open()`**：使えないことを、名前がないエラー（NameError）ではなく、分かるメッセージで伝える

## 結果

- CPython との比較テストに `tests/cases/semantics_phase6_syntax.py` を足した（出力と変数の状態の変化が CPython と一致する）
- 変数の状態の比較（`tests/line-state.test.js`）は、`with`・デコレーター・`match`・`import` の文の始まりでも状態を比べる
- まだ対応していないもの：ジェネレーター（`yield`）、`open()`、`async`、`with` の組み込みのコンテキストマネージャー（ファイルなど）
